If 3x² − 12x + 9 = 0, what are the values of x?

A
x = 1 and x = 3
B
x = 2 and x = 6
C
x = −1 and x = −3
D
x = 4 and x = 0
Correct!

Dividing by 3: x² − 4x + 3 = 0 → (x−1)(x−3) = 0
